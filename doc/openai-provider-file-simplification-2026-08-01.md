# OpenAI 文件功能简化记录

日期：2026-08-01

## 结果

OpenAI 文件功能已经完成，可以通过正常配置启用。项目不再要求独占 Project 声明、真实沙盒证明、外部不可修改存储证明、数据库测试证明或短期签名证明。

本次删除了这些额外限制及其专用代码，包括证明记录、未知文件扫描、沙盒观察测试和后台扫描任务。它们不会再阻止文件上传、查询、请求引用或到期删除。

## 保留功能

- 管理员选择一个官方 OpenAI 单密钥渠道。
- 客户端通过 `POST /v1/files` 上传文件，通过 `GET /v1/files/{file-id}` 查询文件。
- `POST /v1/responses` 可以使用上传后返回的文件标识。
- 系统按配置的保存时间自动删除文件。
- 系统继续核对用户、API Key、渠道和 OpenAI 凭据，防止文件被其他用户或渠道使用。
- 文件原始标识、文件名和凭据不会写入普通日志。

## 启用条件

启用时只需配置：

- 文件功能开关。
- OpenAI 渠道编号。
- 文件保存时间。
- 查询结果的缓存时间。
- 提前删除时间、单批数量、最大尝试次数和单次超时时间。

Project 和 Organization 仍可按普通 OpenAI 渠道配置使用，但不要求声明独占，也不要求提交任何证明。

现有文件生命周期表、自动删除任务、渠道变更保护和错误重试逻辑继续保留。
