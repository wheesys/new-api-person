# 后台渠道能力预览实施记录

日期：2026-07-31

## 结论

默认后台渠道列表已增加“查看能力预览”行操作。管理员可以在不修改渠道、不刷新能力表和不调用上游的前提下，检查当前渠道配置将生成的模型与分组路由组合。

## 实现范围

- 行操作打开独立预览对话框，不挤入已有超长渠道编辑抽屉。
- 展示生成能力总数、去重模型数、去重分组数、优先级、权重、渠道状态和分组列表。
- 模型表展示请求模型与 `model_mapping` 解析后的上游模型；畸形映射回退为请求模型，不阻断预览。
- 最多渲染前 100 个模型，并明确显示可见数与总数，避免超大渠道配置造成对话框卡顿。
- 没有模型或分组时显示空状态，不伪造能力记录。

## 与后端的一致性

后端 `Channel.buildAbilities()` 对 `GetModels()` 和 `GetGroups()` 的笛卡尔积按 `group|model` 去重。前端预览同样先去除空项和重复项，再计算 `models.length * groups.length`，因此数量与后端将写入的能力组合一致。

`ModelMapping` 只决定请求转发时的上游模型名，不会改写 `Ability.Model`。预览同时展示请求模型与映射后的上游模型，但能力计数仍以请求模型和分组为准。

该预览是配置推演，不读取实时 `Ability` 表、不测试渠道连接，也不表示上游当前健康或模型实时可用。
