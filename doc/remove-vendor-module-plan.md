# 移除前端供应商模块实施计划

生成日期：2026-07-03

## 目标

从默认前端页面和后端管理 API 中移除模型资产的 `Vendor` / 供应商管理与展示概念，同时保留渠道、上游适配器和现有数据库字段，避免破坏已有部署数据。

## 范围

- 移除后端 `/api/vendors/*` 管理路由。
- 移除默认前端模型管理页里的供应商按钮、弹窗、筛选、列展示和 API 调用。
- 移除定价页和排行榜中面向用户的供应商筛选、供应商列、供应商区块。
- 模型同步不再创建或更新供应商记录。
- 不删除数据库表或字段，不执行破坏性迁移。

## 验证

- 后端：运行与模型、定价、排行榜相关的 Go 测试。
- 前端：运行默认前端 typecheck/build 或可用的最小验证命令。
- 文档：更新 `doc/todo.md` 和业务关系报告中供应商模块描述。

## 完成情况

- 已移除 `/api/vendors/*` 管理路由和供应商控制器。
- 已移除定价接口 `vendors` 响应字段、`vendor_id` 对外序列化和排行榜供应商聚合响应。
- 已移除默认前端 Models、Pricing、Rankings 页面中的供应商入口、筛选、列展示、链接和市场份额区块。
- 已保留 `vendors` 表和 `models.vendor_id` 字段作为旧部署兼容层，不执行破坏性迁移。
